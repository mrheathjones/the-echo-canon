# The Echo Canon Repository

This repository contains the current master canon bible for **The Echo**, reconstructed from the uploaded full ChatGPT transcript.

## Key Files

- `MASTER_CANON_BIBLE.md` - full current canon bible in Markdown.
- `MASTER_CANON_BIBLE.docx` - formatted Word version.
- `MASTER_CANON_BIBLE.pdf` - PDF export.
- `canon/` - split canonical sections.
- `source/` - uploaded transcript PDF and extracted text.

## Workflow

1. Put rough ideas in `notes/inbox/`.
2. Move locked material to `canon/`.
3. Update `MASTER_CANON_BIBLE.md` when major canon changes.
4. Commit frequently.

## Suggested Commit Messages

- `canon: add Accord structure notes`
- `character: update Abby Whitmore profile`
- `story: outline Book 1 emotional spine`
- `world: refine Echo mechanics`
