# Core Friend Group Overview

Core group: Lucas, Maya, Zoe, Mason, Eli.

Earlier structure: 3 neurodivergent kids and 2 non-neurodivergent kids, but all have meaningful strengths. The theme is not “ND kids are special and everyone else supports them.” Everyone contributes. Everyone is required.

The friend group must be friends first and a team second.

Group principles:
- nobody owns an entire domain
- everybody contributes to both normal and Echo problems
- non-ND friends must be essential, not included as support staff
- each friend should survive as a character if the Echo disappeared
